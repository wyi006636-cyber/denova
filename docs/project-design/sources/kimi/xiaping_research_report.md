# 虾评（xiaping.coze.com）小说写作 Skills 调研报告

> 调研时间：2026-07-20 · 调研方式：FetchURL + 站点公开 API + 技能包 ZIP 实下载分析。所有结论均基于当前轮实际抓取的数据。

## 1. 虾评是什么网站

**虾评Skill**（口号"好技能虾说了算"）是面向 AI Agent 的**精品 Skill 分享与评测平台**，扎根 OpenClaw / Coze（扣子）生态，类似"Agent 技能界的豆瓣 + 应用商店"。站点本身是用字节 Coze Coding 搭建的 Next.js 应用（TOS 对象存储托管技能包）。

注意：第三方导航站常写旧域名 xiaping.coze.site；平台官方指南（/skill.md）明确当前域名为 **xiaping.coze.com**。

**平台机制**：
- 收录规模：全站 450+ 技能（2026-04 第三方报告）；"小说"关键词即搜出 72 条
- 社区评测：虾评员提交 1-5 星 + 文字评测（POST /comments）；平台侧自动跑 SBI 评测；卡片展示下载量、均分、评测数
- 转正机制：新技能为 trial（试用），需约 20 篇评测 + 加权分 >=4 才转 official
- 安全扫描：每条技能带 security_status（safe / safe_checked / safe_duplicate / 风险）+ 完整安全报告（意图分析 vs 实际行为）
- 虾米经济：评测/打卡/分享赚虾米积分，用户等级 A1 至 A5-1
- 安装方式：Agent 复制 curl 口令 -> 下载 ZIP -> 解压即装

**Skill 条目信息**（公开 API `GET /api/skills/<id>` 实测返回）：
id、name、description、trigger（触发关键词）、category、tags、owner_id/owner_name/owner_level、current_version、downloads、avg_stars（x100 存储，463=4.63 分）、weighted_score、star_count、comment_count、is_featured、status（trial/official）、security_status、security_report（长文 Markdown）、version_count、created_at/updated_at。另有文字评测流（`/api/skills/<id>/comments`）。

## 5. 可复用性评估（面向自研小说写作 harness）

**结论：可复用性高。** 这些技能不是 Coze bot 提示词，而是标准 **Agent Skills 规范**（SKILL.md + frontmatter + references + scripts）的 ZIP 包，与 Claude skills / Kimi skills 目录规范同构，解压即可被任何支持 SKILL.md 的 harness 加载；平台也明示"集成到你的系统"。

**复用分层建议**：
1. harness 骨架层：多米长篇（7 阶段门+质量门+沉淀机制）作主干 SOP
