# AI 痕迹词表

用于 `humanize` 第 4 步诊断。词表只是线索：**一个词出现一次不等于有问题，密度、场合和是否作者习惯决定要不要改。** 台词里的同类表达先判断是不是人物自己的说话方式。

每组列出常见形态和改法方向。词表无法穷尽，遇到同类变体按同一思路处理。

## A 组：空泛氛围

把画面交给抽象词和「仿佛」，读者看不到具体东西。

| 常见形态 | 改法方向 |
| --- | --- |
| 空气仿佛凝固 / 凝滞了；气氛一下子安静下来 | 写场景里谁停下了什么、哪个声音突然显得很响 |
| 弥漫着……的气息；……笼罩着整个房间 | 落到一种具体气味、温度或光线上 |
| 交织、斑驳、氤氲、缥缈、幽暗深邃 | 删掉，或换成可以指认的物件与颜色 |
| 某种难以名状 / 说不清的感觉 | 写出那种感觉落在身体或注意力上的样子 |
| 一切都显得那么……；整个世界仿佛…… | 删掉，回到眼前这个人、这件事 |

## B 组：程式化神态与动作

所有角色共用一套表情包，或用固定搭配代替真正的反应。

| 常见形态 | 改法方向 |
| --- | --- |
| 微微一怔、微微一笑、微微点头 | 删「微微」；或换成这个角色才有的小动作 |
| 嘴角勾起一抹（弧度 / 笑意 / 冷笑） | 直接写笑或不笑，或让台词承担态度 |
| 眼中闪过一丝（精光 / 异色 / 复杂） | 写他接下来做了什么，而不是眼睛里闪过什么 |
| 瞳孔骤缩 / 猛地一缩；倒吸一口凉气 | 全场只留给最该震惊的人，其他人换别的反应或不写 |
| 负手而立、眸光流转、眉头微蹙 | 看是否只是装饰；是装饰就删 |
| 身体一僵、心头一颤（多人连续出现） | 给每个人不同的反应速度和方式 |

## C 组：情绪与认知标签

叙述替人物把情绪和领悟直接说出来。

| 常见形态 | 改法方向 |
| --- | --- |
| 他感到愤怒 / 恐惧 / 一阵失落 | 身体反应、注意力落点或下一个决定，选一个 |
| 心中一凛、心头一紧、五味杂陈 | 同上；或用一句带口吻的心里话 |
| 他意识到 / 明白了 / 终于懂了 | 让他做出因为懂了才会做的事 |
| 不由得、不禁、莫名地、下意识地（高频） | 多数可以直接删 |
| 一股暖流涌上心头；心中充满了…… | 删掉，或换成具体的回应动作 |
| 难以言喻、无法形容、宛如实质 | 删掉，或真的去描述 |

## D 组：程度副词与机械连接

用副词加码、用连接词凑逻辑。

| 常见形态 | 改法方向 |
| --- | --- |
| 极其、极度、无比、十分、异常 | 能删就删；删后不够，换成一个能体现程度的细节 |
| 缓缓地、淡淡地、轻轻地、深深地（高频） | 删；或换成动词本身更准确的那个词 |
| 有条不紊、有节奏地、不紧不慢地 | 写出具体怎么做，或删 |
| 与此同时、紧接着、随后、然而（每段开头） | 删掉多余的连接词，让动作顺序自己说明时间 |
| 毫无疑问、显而易见、不得不说 | 删 |
| 不仅……更……；既……又…… | 只保留确实需要并列的地方 |

## E 组：结构与句式

单句没毛病，但组合起来一眼看出是模型写的。

| 常见形态 | 改法方向 |
| --- | --- |
| 段末总结、感悟、升华（「这一刻，他终于明白……」） | 删掉，停在动作、台词或后果上 |
| 三段式排比、成组的对仗句 | 拆开，留最有力的一句 |
| 「不是 A，而是 B」反复出现 | 直接说 B |
| 每段长度、信息密度都差不多 | 紧张处切短，平缓处允许长段 |
| 对话一问一答，每句都完整回答 | 加入回避、打断、答非所问；删掉替读者解释背景的话 |
| 展示之后再解释一遍 | 删解释，信任读者 |
| 章末安全着陆，一切暂时圆满 | 留一个没解决的问题或一点不安 |
| 破折号、省略号成串出现 | 改回句号或逗号 |

## F 组：翻译腔

| 常见形态 | 改法方向 |
| --- | --- |
| 进行了一番 / 进行……的讨论 | 直接用动词：「商量了一阵」 |
| 一个……的笑容 / 一个……的决定 | 去掉「一个……的」，用动词或短句 |
| 被……所……；被迫地 | 改主动语序 |
| 作为一名……，他…… | 删掉身份前缀，或融进动作 |
| 他的眼睛里充满了…… | 改为具体反应 |
| 定语过长：「那个站在门口穿着灰色外套的男人」 | 拆成两句，或先交代人再写动作 |

## 对照示例

以下示例为本技能自写，只示范思路；改写时以原文已有的事实为界。

**示例 1：情绪标签 + 程式化神态（适中）**

> 原句：听到这个消息，林舟微微一怔，心中涌起一股难以言喻的失落，他缓缓地低下头，嘴角勾起一抹苦涩的弧度。
>
> 改后：听到这个消息，林舟没接话。他把手里那张收据对折，又对折，折到折不动为止。

保留：人物、事件、「没有当场反驳」的态度。删掉：四处 B、C、D 组痕迹。新增的「收据」必须是前文已经出现在他手里的东西；如果前文没有，就只写「他低头看着自己的鞋尖，半天没说话」。

**示例 2：段末升华（轻度）**

> 原句：……她把药碗推回桌上，转身出了门。这一刻，她终于明白，有些路只能一个人走下去。
>
> 改后：……她把药碗推回桌上，转身出了门。

只删最后一句。轻度不改前面的叙述。

**示例 3：台词播报（适中）**

> 原句：「我们三天前就已经查过那个仓库了，里面除了一些废弃的木箱之外什么都没有，所以你说的那个人不可能藏在那里。」
>
> 改后：「仓库？三天前就翻过了。一堆烂木箱，藏得住谁。」

信息（三天前查过、只有木箱、人不在那）和立场不变；去掉了完整书面回答和连接词。人物原本说话就文绉绉时不要这样改。

**示例 4：空泛氛围（大幅）**

> 原句：夜色笼罩着整座城市，空气中弥漫着压抑的气息，一切都显得那么寂静。
>
> 改后：过了十点，街上的店铺陆续拉下卷帘门，最后一声落在街口那家面馆。

只用了「城市夜晚」本身必然存在的东西。大幅允许重组整句，但不能借机加入新的人物或事件。
